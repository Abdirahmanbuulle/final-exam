About DineQR

DineQR is a smart, cloud-based restaurant system that allows customers to scan a QR code, view the menu, place orders, and pay directly from their phones. Staff and managers use a POS dashboard to manage orders, track sales, and analyze performance.

Objectives

  • Simplify restaurant operations through a digital, fast, and contactless ordering system.
  • Improve customer satisfaction by reducing wait times.
  • Provide real-time analytics for management.
  • Create an eco-friendly, paperless solution.

Technologies Used

  • HTML, CSS, JavaScript, Bootstrap 5
  • Node.js / Django (backend)
  • MySQL / MongoDB (database)
  • Stripe / PayPal (payment gateway)

Features

  • Digital QR menu
  • Online order placement
  • Payment processing
  • Order tracking and management
  • Admin dashboard for analytics and reports
